# **App Name**: ChordFlash

## Core Features:

- Chord Display: Display song title and chords (using <pre> formatting) in a card layout.
- Song Navigation: Navigation buttons to move between songs.
- PWA Support: Enable the app to be installed as a PWA on mobile devices.
- Add Song: Allow users to add new songs with titles and chords directly within the app, storing them locally.
- Edit Song: Provide options to edit existing songs.
- Delete Song: Include an option to delete songs from the local storage.

## Style Guidelines:

- Background color: Dark gray (#222222) for a night-friendly mode suitable for performances.
- Primary color: A vibrant orange (#E67700) to ensure readability against the dark background.
- Accent color: A complementary yellow (#E6B800) to highlight interactive elements.
- Use a clean, legible sans-serif font to make the chords easily readable.
- Mobile-first responsive design, ensuring smooth usage on smartphones.
- Rounded borders to soften the UI, making it visually comfortable for musicians.
